DEZ MRS Luxury Dashboard — دليل الاستخدام 
===================================

أولاً: شو تم عمله بالمشروع (باختصار)
------------------------------------------------------------
سابقاً، بيانات الداشبورد كانت "مثبّتة" داخل ملف الـ HTML نفسه — أي إنه أي
تعديل عالإكسل ما كان بينعكس على الصفحة إلا إذا تم إعادة بناء الملف يدوياً.

الآن صار عندنا نظام "قراءة مباشرة": صفحة الداشبورد (HTML) بتفتح ملف
الإكسل (DEZ_MRS_Dashboard.xlsx) مباشرة من نفس المجلد في كل مرة حدا
يفتح الرابط، وبتحسب كل الأرقام والرسوم والجداول والتوصيات تلقائياً
من محتوى الإكسل الحالي.

يعني عملياً:
  - أي تعديل تعمله على الإكسل (إضافة/حذف/تعديل سجل، تغيير أولوية...)
    بيظهر تلقائياً على الداشبورد بدون أي خطوة برمجية إضافية.
  - أي شخص يفتح رابط الداشبورد ما بيحتاج يكون عنده ملف الإكسل عالجهاز؛
    الصفحة نفسها بتجيبه من نفس المجلد على GitHub.

الملفات الموجودة داخل المشروع:
  - DEZ_MRS_Luxury_Decision_Dashboard.html  → صفحة الداشبورد نفسها
  - DEZ_MRS_Dashboard.xlsx                  → مصدر البيانات (هذا الملف
                                               اللي بيتعدل)
  - README_AR.txt                           → هذا الملف

=================================

ثانياً: كيف تعدل على الإكسل والتحديث يظهر للجميع على الرابط
=================================

الخطوة 0 — الحصول على صلاحية دخول للـ repo (مرة وحدة بس)
------------------------------------------
لازم يكون عنده حساب GitHub، وتتم إضافته كـ Collaborator على الـ repo:
  Settings (بالـ repo) → Collaborators and teams → Add people
  → إدخال اسم مستخدمه أو إيميله → إرسال الدعوة.
هو بيستلم إشعار/إيميل ولازم يقبل الدعوة قبل ما يقدر يعدل.

الخطوة 1 — تحميل نسخة من الإكسل الحالي
------------------------------------------
  1) يدخل على صفحة الـ repo على GitHub.
  2) يدوس على ملف DEZ_MRS_Dashboard.xlsx.
  3) يدوس على أيقونة التحميل (Download raw file).
  4) يفتح الملف عنده بالإكسل (Excel / Google Sheets) ويعدل عليه بشكل
     طبيعي — إضافة صفوف، تعديل قيم، حذف سطر... إلخ.

الخطوة 2 — رفع النسخة المعدّلة (Upload)
------------------------------------------
  1) يرجع لصفحة الـ repo الرئيسية على GitHub.
  2) يدوس Add file → Upload files.
  3) يسحب أو يختار الملف المعدّل من جهازه.
  4) **مهم جداً:** لازم يبقى اسم الملف نفسه بالضبط:
        DEZ_MRS_Dashboard.xlsx
     (إذا انرفع باسم مختلف، الصفحة ما رح تلاقيه.)
  5) تحت بيطلع صندوق "Commit changes" — يكتب وصف بسيط (مثلاً:
     "تحديث بيانات حي البعاجين") ويدوس Commit changes مباشرة على
     الفرع الرئيسي (main).

الخطوة 3 — التحقق من ظهور التحديث
----------------------------------------------
  - GitHub Pages بياخد عادة دقيقة أو دقيقتين حتى يحدّث الموقع.
  - أي حد يفتح رابط الداشبورد بعدها رح يشوف البيانات الجديدة تلقائياً.
  - إذا ما ظهر التحديث فوراً، يعمل Hard Refresh للصفحة:
        Windows/Linux:  Ctrl + Shift + R
        Mac:            Cmd + Shift + R
    (هاد بيلغي النسخة المخزنة "cache" بالمتصفح ويجيب أحدث نسخة.)

===================================

ثالثاً: شروط لازم يحافظ عليها بملف الإكسل حتى تستمر الصفحة تشتغل
===================================
  1) اسم الشيت اللي فيه البيانات لازم يبقى بالضبط:  Clean Data
  2) أسماء الأعمدة لازم تبقى بنفس الترتيب والتسمية بالضبط:
        Index, City, Neighborhood, Problem, Main Problem Class,
        Secondary Problem Class, Cause, Result, Priority, SDG,
        PLERP, Dialogue Stakeholders, Recommended Solution,
        Solution Class, Year
  3) يقدر يضيف صفوف جديدة بحرية كاملة (الداشبورد بيتأقلم تلقائياً مع
     أي عدد سجلات، وعدد السجلات بالشريط الجانبي بيتحدث لحاله).
  4) ممنوع تغيير اسم ملف الإكسل نفسه (DEZ_MRS_Dashboard.xlsx) إلا إذا
     تم تعديل اسمه بالكود أيضاً.

============================================================

رابعاً: إذا الملف انفتح مباشرة من الجهاز (بدون GitHub Pages)
============================================================
فتح ملف HTML بنقرة مزدوجة من الجهاز (بدون رابط GitHub Pages) ممكن
المتصفح يمنعه من قراءة ملف الإكسل تلقائياً لأسباب أمنية. بهاي الحالة
بيظهر تلقائياً بالصفحة خيار "اختيار الملف يدوياً" يقدر يستخدمه لفتح
نفس ملف الإكسل يدوياً والداشبورد بيشتغل عادي.
الحل الأضمن دائماً هو فتح الرابط عبر GitHub Pages مباشرة.
